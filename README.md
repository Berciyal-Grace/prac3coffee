# Month Finder

A simple web project that displays the month name based on the number entered by the user.

## Features

- Enter a number from 1 to 12
- Displays the corresponding month
- Simple and beginner-friendly interface
- Built using HTML, CSS and JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter a number between 1 and 12.
2. Click the **Show Month** button.
3. The corresponding month will be displayed.
